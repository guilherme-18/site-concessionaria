#### sobre o site da *Pathyonni Car*

O site da **Pathyonni Car** é um projeto desenvolvido para apresentar uma loja fictícia de carros, destacando diferentes modelos de veículos, desde carros esportivos a carros luxuosos.

O site possui páginas como:

- **Início:** apresenta a marca, recomendações de veículos e destaques de carros.
- **Carros:** exibe um catálogo de veículos com imagens, nomes, preços ilustrativos e links para sites oficiais das fabricantes.
- **Fale Conosco:** apresenta um formulário para dúvidas e solicitações de informações.

O projeto utiliza imagens, vídeos, links externos e elementos visuais para tornar a navegação mais interessante e apresentar os veículos de forma organizada.

##### objetivo

O projeto foi desenvolvido como parte de um trabalho escolar do *curso de Análise e Desenvolvimento de Sistemas (ADS)*, com o objetivo de aplicar os conhecimentos adquiridos durante o curso na criação e estilização de páginas web.

Atualmente, o **site ainda está incompleto e poderá receber novas páginas, funcionalidades, melhorias visuais e outros conteúdos futuramente**. Trata-se de um projeto acadêmico, desenvolvido para fins educacionais, e não de uma loja virtual comercial finalizada.

O desenvolvimento utiliza **HTML e CSS puro**, sem JavaScript e sem banco de dados. Portanto, o foco está na estruturação das páginas, na estilização dos elementos, na organização das informações e na prática dos fundamentos do desenvolvimento web. O formulário de contato é apenas visual e não possui integração com um sistema para armazenar ou enviar as mensagens.
